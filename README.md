# SpaceX Falcon 9 – Applied Data Science Capstone

This repository implements the full capstone workflow: API collection, web scraping, wrangling, EDA, SQL, Folium, Plotly Dash and predictive classification.

## Research question
Can historical Falcon 9 launch characteristics help predict successful first-stage landing?

## Run order
01 API → 02 Web Scraping → 03 Wrangling → 04 EDA Visualization → 05 SQL → 06 Folium → 07 Dash → 08 Machine Learning

The API notebook records the live API response and uses a public course-compatible dataset if the endpoint is temporarily unavailable.
